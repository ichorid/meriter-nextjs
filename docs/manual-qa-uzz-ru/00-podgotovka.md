# Сессия 00 — Подготовка

**Сайт:** https://uzz-dev.meriter.pro

## Что взять с собой

- Chrome или Firefox, актуальная версия.
- Почта аккаунта **А** (и **Б**, если выдан).
- Telegram, которым будете привязывать аккаунты (не чужой боевой, если команда просила тестовый).
- Два окна: обычное + инкогнито.
- Ширины: **1280 px** (десктоп) и **390 px** (DevTools → iPhone).
- Блокнот для email, времени письма, ID сделки.

У команды заранее спросить:

- Оба аккаунта уже **в пилотном сообществе** и с **заслугами**?
- У А есть **активный банк** с номиналом? Если нет — админ назначит номинал в сессии 05, либо команда выдаст банк.
- У Б есть **карточка услуги** в каталоге? Если нет — Б создаст её в сессии 03.
