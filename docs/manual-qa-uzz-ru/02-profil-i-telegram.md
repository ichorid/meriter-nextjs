# Сессия 02 — Профиль и Telegram

**Сайт:** https://uzz-dev.meriter.pro  
**Роль:** аккаунт А (залогинен). Затем то же для Б.

Привязка Telegram **обязательна** для сделок и кошелька. Без неё сессия 04 остановится.

## Профиль

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 2.1 | Открыть `/profile` | Блоки «Аккаунт» и «Связка» | | |
| 2.2 | Имя и сообщество | Имя не пустой мусор; указано сообщество пилота | | |
| 2.3 | Ссылка «Кошелёк» | Ведёт на `/wallet` | | |
| 2.4 | «Настройки платформы» | Видна **только** если А — админ сообщества/площадки. У обычного участника пункта **нет** | | |
| 2.5 | Навигация шапка (1280) | Обмен, Моё, Сделки, Кошелёк, Профиль | | |
| 2.6 | Если админ | Пункт называется **«Настройки платформы»**, не «Управление пилотом» | | |

## Привязка Telegram (новое окно)

Разрешите всплывающие окна для uzz-dev.meriter.pro до шага 2.8.

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 2.7 | Если Telegram не привязан | Кнопка «Привязать Telegram», статус «Не завершена» | | |
| 2.8 | Нажать «Привязать Telegram» | Открывается **новое окно/вкладка** Telegram (или бот), исходная страница профиля **остаётся** | | |
| 2.9 | Если браузер блокирует окно | Понятное сообщение про всплывающие окна, не молчаливый провал | | |
| 2.10 | Завершить привязку в боте | На профиле: Telegram привязан (username `@…` или «Привязан»), бейдж «Готово» | | |
| 2.11 | Обновить профиль | Связка не слетает | | |
| 2.12 | Повторно «Привязать» | Кнопки нет или сценарий безопасен (не создаёт вторую личность) | | |

## Гейт «сначала привяжите Telegram»

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 2.13 | До привязки открыть `/deals` или `/wallet` | Экран «Привяжите Telegram», а не пустой список с ошибкой API | | |
| 2.14 | С каталога заявка без связки | Кнопка «Сначала привяжите Telegram» → переход в профиль | | |
| 2.15 | После связки открыть `/deals` | Список сделок или пустое состояние, **без** гейта | | |

Повторить 2.7–2.12 для аккаунта **Б**.
