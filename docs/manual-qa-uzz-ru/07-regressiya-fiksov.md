# Сессия 07 — Регресс фиксов заявок

**Сайт:** https://uzz-dev.meriter.pro  
**Когда:** после сессий 03–04 или отдельным коротким прогоном на свежем выкате.  
**Не цель:** полный повтор цикла сделки — только пункты, которые уже ломались на стенде.

Нужны: аккаунт А с банком и комиссией; карточка Б **онлайн без места** (сессия 03.14). Если такой карточки нет — создать перед стартом.
