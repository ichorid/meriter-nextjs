# Сессия 07 — Регресс фиксов заявок

**Сайт:** https://uzz-dev.meriter.pro  
**Когда:** после сессий 03–04 или отдельным коротким прогоном на свежем выкате.  
**Не цель:** полный повтор цикла сделки — только пункты, которые уже ломались на стенде.

Нужны: аккаунт А с банком и комиссией; карточка Б **онлайн без места** (сессия 03.14). Если такой карточки нет — создать перед стартом.

---

## A. Пустой срок и календарь

| № | Что сделать | Ожидаемый результат | Фактически | OK |
|---|-------------|---------------------|------------|-----|
| 7.1 | Заявка на карточку Б: сообщение «Тест», срок не трогать | На кнопке срока «Не указан» | | |
| 7.2 | «Подтвердить заявку» | Успех, редирект на сделки. **Не** «Проверьте поля формы: данные не прошли проверку» | | |
| 7.3 | Открыть календарь | Месяц, дни, часы, минуты, «Сбросить», «Готово». Нет нативного `datetime-local` Windows | | |
| 7.4 | Кликнуть прошедший день | День не выбирается (disabled) | | |
| 7.5 | Выбрать будущий день, время, «Готово» | На кнопке читаемая дата (например «20 авг. 2026, 18:00») | | |
| 7.6 | «Сбросить» и снова отправить заявку (если предыдущую отменили/отклонили) | Пустой срок снова допустим | | |

## D. Раунд 2 — фиксы по отчёту тестера от 20 авг.

Нужны: аккаунт Б **без публичного @username** в Telegram (Настройки → Имя пользователя пустое); аккаунт админа.

| № | Что сделать | Ожидаемый результат | Фактически | OK |
|---|-------------|---------------------|------------|-----|
| 7.12 | Б без @username: А оставляет заявку, Б жмёт «Рассмотреть и принять» → «Принять на N ₽» | Сделка принимается. **Нет** 400 и **нет** «Контакт исполнителя ещё не готов» | | |
| 7.13 | После принятия открыть карточку сделки у обеих сторон | У стороны без @username кнопка **«Открыть чат в Telegram»** и пояснение; у стороны с @username — «Написать @…» | | |
| 7.14 | Админ: «Правила пилота» → нижний номинал 500 → «Сохранить настройки» → «Применить изменения» | Сохранено. Значение осталось 500 после перезагрузки страницы, **не** откатилось к 100 | | |
| 7.15 | Там же: блок «Назначение номинала» → «Сохранить назначение номинала» | Сохраняется без ошибки. В подсказке «Не ниже нижнего номинала (500 ₽)» | | |
| 7.16 | «Моё» → «Добрые дела» при посте, уже набравшем порог, но без банка | Банк появляется, бейдж «Банк создан»; на вкладке «Банки» он виден | | |
| 7.17 | «Моё» → «Мои услуги» с 3+ карточками разной длины, ширина 390 | Кнопки «Редактировать» / «Скрыть из каталога» под своей карточкой, ничем не перекрыты | | |
| 7.18 | Там же нажать «Редактировать» на верхней карточке | Форма раскрывается целиком внутри своей карточки, поля доступны | | |
| 7.19 | Каталог: карточка с длинным описанием рядом с короткой | Описание обрезано (4 строки, «…»), высота ряда не разъезжается | | |
| 7.20 | Открыть заявку по этой карточке | В диалоге **полное** описание в прокручиваемом блоке; заголовок услуги не задвоен | | |
| 7.21 | Диалог заявки, любой | Фон затемнён и размыт, бейджи и текст под ним не просвечивают | | |
| 7.22 | Ширина 1280, есть заявка, требующая ответа | Счётчик стоит **рядом** со словом «Сделки», не поверх него | | |
| 7.23 | Ширина 390, аккаунт админа | Все 6 пунктов нижнего меню одной высоты, последний подписан «Настройки» | | |
| 7.24 | Кошелёк: операция «Комиссия возвращена» после истечения заявки | Подпись **«Заявка истекла по сроку»**, английского `expired` нет | | |
| 7.25 | Кошелёк с дробным балансом (например 0,5) | «0,5 заслуги», не «0.5 заслуга» | | |
| 7.26 | Бот: начислить автору 1 заслугу, затем 2 | «начислил автору 1 заслугу», «2 заслуги», не «1 заслуг» | | |
| 7.27 | Заявка: открыть календарь, пролистать на 3 месяца вперёд, «Готово» без выбора, открыть снова | Календарь на текущем месяце | | |
| 7.28 | Каталог у участника с привязкой, без банков и без своих услуг | Полоска «Как это работает» из 3 шагов; крестик скрывает её и она не возвращается после перезагрузки | | |
| 7.29 | Форма услуги | У полей «Длительность», «Место», «Доступность» подсказки про свободный текст | | |
| 7.30 | Страница входа | «Введите email — пришлём одноразовую ссылку для входа. Пароль не нужен.» | | |

Если 7.12, 7.14 или 7.16 красные — **блокер**: это те же дефекты, что закрывались в этом раунде.

Если 7.2 или 7.8 красные — это **блокер** основного флоу. Оформить по шаблону README.
