# Сессия 04 — Кошелёк и сделки

**Сайт:** https://uzz-dev.meriter.pro  
**Роли:** А — заказчик, Б — исполнитель. Оба с Telegram. У А активный банк ≥ цены карточки Б. У обоих ≥ 1 заслуги на комиссию.

Зафиксируйте в блокноте: цена карточки, номинал банка А до заявки, баланс сообщества и общий баланс А до/после.

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 4.1 | Открыть Кошелёк | Пояснение: это **не** номинал банка; комиссия 1 заслуга | | |

## Полный цикл (главный сценарий)

Карточка Б в каталоге, цена **ниже** номинала банка А. Не берите карточку самого А.

### Заявка (А)

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 4.6 | Каталог → карточка Б → «Оставить заявку» | Диалог: выбор банка, сообщение, опциональный срок | | |
| 4.7 | Пустое сообщение → отправить | Не уходит, нужна формулировка | | |
| 4.8 | Срок «вчера» / слишком близко | Ошибка «срок должен быть в будущем» (или аналог) | | |
| 4.9 | Нормальное сообщение + отправка | Редирект на `/deals`, зелёная вспышка: заявка отправлена, **зарезервирована 1 заслуга** с сообщества или общего кошелька | | |
| 4.10 | Кошелёк А сразу после | −1 заслуга в том источнике, что указан во вспышке | | |
| 4.11 | Банк А | Статус вроде «в сделке», этим банком нельзя подать вторую заявку | | |
| 4.12 | Сделка у А | «Вы заказчик», статус «Ждём ответа исполнителя». **Нет** ссылки t.me на Б | | |
| 4.13 | Бейдж в меню «Сделки» | У Б должен появиться счётчик действия (если реализован) | | |

| 4.18 | Контакт до принятия (контроль) | В истории старых `requested` контакта нет | | |

## Ветки отказа (отдельные заявки)

Нужны ещё две коротких заявки на **другую** карточку или ту же после закрытия, с достаточным банком.

### Отклонение исполнителем

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 4.25 | А создаёт заявку, Б жмёт отклонить | Вспышка: комиссия и банк **возвращены** заказчику | | |
| 4.26 | Кошелёк А | +1 заслуга к тому источнику, откуда резервировали | | |
| 4.27 | Банк А | Снова активен, можно заказывать | | |
| 4.28 | Контакт | Так и не открылся | | |

### Отмена заказчиком до принятия

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 4.29 | А создаёт заявку и сам отменяет, пока Б не принял | Возврат комиссии и банка | | |
| 4.30 | После принятия А пытается отменить | Нельзя (сообщение вроде «после принятия заказчик не может отменить») | | |

### Негативные проверки каталога

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 4.31 | Услуга дороже номинала банка | Кнопка «Нужен больший номинал», заявка не уходит | | |
| 4.32 | Нулевой баланс заслуг (если удастся) | «Не хватает заслуги на комиссию» | | |

Демо-сделки NPC в списке можно смотреть, но не считать их своим циклом.
