## Формулировки (регресс копирайта)

Пройтись глазами. В пользовательских фразах про обмен — **банк**, не «право на обмен». Исключение: «права администратора», «недостаточно прав».

| Шаг | Где | Ожидалось | Фактически | OK |
|-----|-----|-----------|------------|-----|
| 6.10 | Моё, вкладки | «Банки» | | |
| 6.11 | Гостевой `/` | «банк на обмен», таяние, переход целиком | | |
| 6.12 | Каталог, баннеры | «загрузить банки», не «права» | | |
| 6.13 | Кошелёк, пустая история | «передача банка» | | |
| 6.14 | Карточка закрытой сделки | «Банк передан целиком, без сдачи» | | |
| 6.15 | Админ, правила | «Появился банк на обмен» в галках Telegram | | |
| 6.16 | Шапка админа | «Настройки платформы» | | |
| 6.17 | Валюта | Везде **заслуги**, нет «мериты» / credits | | |
