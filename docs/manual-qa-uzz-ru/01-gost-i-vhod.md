# Сессия 01 — Гость и вход

**Сайт:** https://uzz-dev.meriter.pro  
**Окно:** инкогнито (гость), затем аккаунт А.

## Гость (без входа)

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 1.1 | `/catalog` без сессии | Список услуг (или пустое состояние). **Нет** Telegram-контактов и ссылок `t.me/` у исполнителей | | |
| 1.2 | Карточка чужой услуги | Кнопка вроде «Войти, чтобы оформить», не «Оставить заявку» | | |
| 1.3 | Нажать эту кнопку | Переход на `/login` (можно с `?next=` на каталог) | | |
| 1.4 | Шапка | Есть «Войти». Разделы «Сделки», «Кошелёк», «Настройки платформы» **не** доступны как рабочие (редирект на вход или скрыты) | | |
| 1.5 | Прямой заход `/deals`, `/wallet`, `/admin`, `/profile` | Редирект на вход, не «сырая» ошибка API | | |
| 1.6 | `/` (Моё) без входа | Гостевой экран: шаги «доброе дело → банк → обмен». Слово **банк**, не «право на обмен» | | |
| 1.7 | Нижнее меню на ширине 390 | Пункты Обмен / Моё / Сделки / Кошелёк / Профиль читаются, не обрезаны в кашу | | |

## Magic link (аккаунт А)

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 1.13 | Ввести email А → «Получить ссылку» | Сообщение: письмо отправлено на этот адрес; подсказка проверить спам | | |
| 1.14 | Подождать до 2 минут, проверить Входящие, Спам, Рассылки | Письмо от площадки «Услуги за заслуги» (или аналог) | | |
| 1.15 | Открыть ссылку **в том же браузере**, где нужна сессия А | Вход выполнен, редирект в приложение (каталог или сохранённый `next`) | | |
| 1.16 | Повторно открыть **ту же** ссылку | Понятная ошибка («ссылка недействительна или устарела»), не белый экран и не вход под чужим | | |
| 1.17 | С каталога гостем нажать вход, затем войти | После входа снова каталог, а не «пустой» корень без причины | | |

Если письма нет: подождать, повторить через минуту, зафиксировать время. Не считать сразу блокером до проверки спама и лимита отправки.
