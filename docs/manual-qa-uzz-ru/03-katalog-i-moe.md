## Каталог `/catalog`

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 3.1 | Открыть Обмен | Заголовок про услуги сообщества; карточки NPC и/или живых людей | | |
| 3.2 | Нет ошибки условий | **Нет** баннеров «Не удалось проверить правила покупки» и «Не удалось загрузить условия» | | |
| 3.3 | Своя карточка (если есть) | Бейдж «Ваше предложение», без заявки на самого себя | | |
| 3.4 | Чужая карточка, банк покрывает цену, комиссия есть | Кнопка **«Оставить заявку»** активна | | |
| 3.5 | Мягкая рекомендация | Если услуг меньше рекомендованных — синяя подсказка «Добавьте ещё N», обмен **не** блокируется | | |
| 3.6 | Поиск по слову из названия | Список сужается, без ошибки | | |
| 3.7 | Чекбокс «Доступно онлайн» | Офлайн-карточки пропадают | | |
| 3.8 | «По карману» | Остаются услуги не дороже вашего максимального номинала банка | | |
| 3.9 | Цена на карточке | Это порог номинала банка в ₽, не «цена в заслугах» | | |
| 3.10 | Открыть диалог заявки и закрыть | Диалог закрывается, ошибка не залипает | | |

Если 3.2 красный — скорее всего нет членства в пилоте. Не продолжать сделки, вернуть команде.

## Создание услуги (аккаунт Б, затем А по желанию)

Нужна **хотя бы одна активная карточка у Б** для сессии 04.

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 3.11 | Моё → вкладка «Мои услуги» → «Добавить услугу» | Форма: название, описание, цена ₽, онлайн/офлайн и т.д. | | |
| 3.12 | Название из 1–2 букв → опубликовать | Ошибка: название 3–120 символов, форма не молчит | | |
| 3.13 | Дробная цена (12.5) | Не принимается, нужна целая сумма ₽ | | |
| 3.14 | Корректная карточка дешевле номинала банка А | Появляется в «Мои услуги» и в каталоге | | |
| 3.15 | «Скрыть из каталога» | В каталоге чужим не видна (или неактивна) | | |
| 3.16 | «Вернуть в каталог» | Снова видна | | |
| 3.17 | Редактировать название | Сохраняется, в каталоге новое имя | | |

## Банки — вкладка «Банки» на `/`

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 3.18 | Вкладка называется **«Банки»**, не «Права» | Да | | |
| 3.19 | Пояснение | Банк ≠ кошелёк заслуг; условная сумма для заказа | | |
| 3.20 | Если банк есть | Статус (ожидает номинал / активен / в сделке), переходы, «завтра» ₽ | | |
| 3.21 | Если банков нет | Пустое состояние про порог заслуг, без слова «право» | | |
