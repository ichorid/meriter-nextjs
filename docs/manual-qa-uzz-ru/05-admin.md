# Сессия 05 — Настройки платформы

**Сайт:** https://uzz-dev.meriter.pro  
**Роль:** аккаунт с пунктом «Настройки платформы» в шапке.  
Если пункта нет — вся сессия `N/A`, внизу напишите чей аккаунт проверяли.

**Опасно:** блок «Сообщество площадки» меняет сообщество **для всего стенда**. Без явной просьбы лида **не сохраняйте** другой пункт. Достаточно убедиться, что список открывается.

## Доступ

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 5.1 | Обычный участник (Б) → `/admin` | Пустое состояние «Нужны права администратора», не настройки | | |
| 5.2 | Админ → шапка и мобильное меню | Пункт **«Настройки платформы»** | | |
| 5.3 | Профиль админа | Та же ссылка | | |
| 5.4 | Страница `/admin` | Eyebrow «Настройки платформы», блоки: сообщество, правила, номинал, сделки, журнал | | |

## Сообщество площадки

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 5.5 | Селект «Сообщество» | Список сообществ, **в которых состоит этот админ**; текущий пилот выбран | | |
| 5.6 | Кнопка «Сохранить сообщество» | Неактивна, пока выбор = текущему | | |
| 5.7 | Выбрать другое (если есть) **и не сохранять** | Можно вернуть селект назад. **Не нажимать сохранить** | | |
| 5.8 | Сохранение другого сообщества | **Только если лид письменно попросил.** После сохранения весь стенд (включая гостей) показывает новое имя на каталоге | | |

## Правила пилота

Меняйте значения **осторожно** и верните как было, если меняли. Запишите исходные числа до правок.

| Шаг | Действие | Ожидаемый результат | Фактически | OK |
|-----|----------|---------------------|------------|-----|
| 5.9 | Поля | Порог заслуг; переходов банка; таяние ₽/день; нижний номинал; рекомендовано карточек; режим взаимности; сроки заявки/исполнения/подтверждения | | |
| 5.10 | Режим взаимности | По умолчанию «Мягкая рекомендация». «Обязательный минимум» не включать на общем стенде без лида | | |
| 5.11 | Дробь в «Таяние» (12.5) | Не сохраняется, подсказка про целое число | | |
| 5.12 | Смена нижнего номинала или сроков | Сначала предупреждение, нужны «Применить изменения», не молчаливый save | | |
| 5.13 | Telegram-уведомления | Четыре галки: появился банк; заявка/отмена; принята/сделана; закрыта. Сохраняются | | |
| 5.14 | Сохранить без опасных полей | «Настройки сохранены» | | |

Если что-то меняли — **верните исходные значения** и сохраните снова.
