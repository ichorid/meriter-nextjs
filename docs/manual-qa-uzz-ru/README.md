# Ручное тестирование «Услуги за заслуги» (uzz-dev)

Полный прогон платформы **через интерфейс**. Автотесты и серверные скрипты в этот план не входят.

**Сайт:** https://uzz-dev.meriter.pro  
**Вход:** только email (одноразовая ссылка из письма). Пароля нет.  
**Telegram-вход на этой площадке нет** — Telegram привязывается уже после входа, из профиля.

Перед стартом уточните у команды, выкатан ли на стенд последний `dev` (формулировка «банк на обмен», пункт «Настройки платформы»). Если нет — строки про новую копирайту и смену сообщества отметьте `N/A` и напишите, какая формулировка была на экране.

---

## Роли на прогоне

| Роль | Кто | Зачем |
|------|-----|--------|
| **А — заказчик** | Основной тестовый аккаунт | Каталог, заявка, кошелёк, банки |
| **Б — исполнитель** | Второй аккаунт (инкогнито / другой браузер) | Карточка услуги, принятие заявки, контакт |
| **Гость** | Без входа (инкогнито) | Каталог без контактов, вход |
| **Админ площадки** | Аккаунт с пунктом «Настройки платформы» | Правила, номинал, спорные сделки |

А и Б должны быть **участниками пилотного сообщества** и иметь **привязанный Telegram**. Иначе сделки не пройти.

NPC в каталоге (Анна, Иван и т.д., почта `@uzz-demo.invalid`) — декорации стенда. **Не пытайтесь войти** под этими адресами.

## Словарь (не путать)

| Термин | Что это | Чего это не есть |
|--------|---------|------------------|
| **Заслуги** | Внутренняя валюта. Комиссия за заявку = **1 заслуга**. | Не рубли и не номинал банка |
| **Банк на обмен** | Условная сумма в ₽, в пределах которой можно заказать услугу. После закрытия сделки банк **целиком** переходит исполнителю, без сдачи. Номинал каждый день немного тает. | Не кошелёк заслуг |
| **Кошелёк** | Заслуги для комиссии: сначала кошелёк сообщества, затем общий | Не номинал банка |
| **Доброе дело** | Пост в Telegram-сообществе, который копит заслуги до порога | Не карточка услуги |
| **Карточка / услуга** | Предложение в каталоге | Не банк |

В интерфейсе ожидается слово **«банк»**, не «право на обмен». «Права администратора» / «недостаточно прав» — это про доступ, их не менять.

## Критерий «прогон принят»

- [ ] Сессии **00–03, 06** без блокеров.
- [ ] Сессия **04**: полный цикл сделки А↔Б закрыт, комиссия 1 заслуга списана/возвращена корректно.
- [ ] Сессия **05** пройдена или `N/A` (нет админ-доступа) с пометкой.
- [ ] Нет утечки контактов Telegram **до** принятия заявки.
- [ ] Нет входа паролем / Telegram-виджета / кнопки «тестовый вход».
- [ ] Блокеры оформлены и переданы команде.

## Как оформлять дефект

```
ID: UZZQA-ГГГГММДД-NN
Сессия: 03
Шаг: 3.12
Серьёзность: Блокер | Критичный | Серьёзный | Незначительный
URL: https://uzz-dev.meriter.pro/...
Роль: А / Б / гость / админ
Шаги воспроизведения:
1. …
Ожидалось: …
Фактически: …
Скриншот / видео: …
Браузер: Chrome / Firefox / Safari, версия
Ширина окна: 1280 / 390
```

**Блокер** — нельзя войти, каталог пустой с ошибкой, сделка ломает деньги, утекли контакты.  
**Критичный** — основной флоу сделки/банков не проходит.  
**Серьёзный** — обходной путь есть, но пользователь спотыкается.  
**Незначительный** — копирайт, отступы, мелочи.

## Не баг (не заводить)

- Нет пароля и нет виджета Telegram на `/login`.
- Нет кнопки «Тестовый вход» / fake user на uzz-dev.
- Письмо пришло в «Спам» / «Рассылки» — сначала проверить эти папки.
- Повторная отправка ссылки сразу после первой может быть ограничена по времени — подождать минуту.
- NPC `@uzz-demo.invalid` не входят и не принимают заявки.
- Контакт исполнителя скрыт, пока заявка в статусе «Ждёт ответа».
- Банк уходит целиком, «сдачи» в рублях нет.
- Смена сообщества площадки без команды лида **не тестировать** (ломает стенд для всех).
- meriter.pro / dev.meriter.pro — другая платформа, не этот прогон.

## Два окна

- Окно А: обычный профиль браузера.
- Окно Б: **инкогнито** (или другой браузер), другой email.
- Не ходить в одном сеансе под двумя людьми: сессия перезапишется.
