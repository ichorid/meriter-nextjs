# «Услуги за заслуги» Implementation Plan

> **For agentic workers:** Implement task-by-task. Spec: [`docs/business-docs-ru/16-uslugi-za-zaslugi-mvp.md`](../../business-docs-ru/16-uslugi-za-zaslugi-mvp.md).

**Goal:** Ship a necessary-and-sufficient UZZ pilot: email login, TG↔email link, banks from good-deed threshold, catalog, deals with escrow, demurrage cron, admin nominal — on shared API + new `uzz-web`, verified on dev before `cw.ru`.

**Architecture:** Clone `community-web` isolation pattern (`meriter_uzz_session`, `/trpc/uzz`, `x-meriter-product: uzz`). New domain under `domain/models/uzz/` + `application/use-cases/uzz/` + thin `adapters/trpc/handlers/uzz-app.router.ts`. Reuse wallet, TG bot, magic-link infra with product-aware cookies/redirects.

**Tech Stack:** NestJS + tRPC + Mongo/Mongoose, Next.js 16 (`uzz-web` :8004), existing Telegram bot, email magic link.

## Global Constraints

- No Telegram Login Widget; email magic link only for site session.
- UI copy: Заслуги / банк / доброе дело — never «мериты»/token/Gesell in UI.
- Defaults: emissionThreshold=10, bankInitialHops=10, demurrageRubPerDay=100, nominalFloorRub=100, purchaseGate=nudge, bankTransferMode=escrow_until_close, minLotsToBuy=3.
- Dev first; cw.ru deploy is a separate final step.
- Do not drag ОБ/Биржа/tappalka/invest into uzz-web.

## Tasks

### Task 1: Product isolation + magic-link for uzz

- Extend `MeriterProduct` with `'uzz'`; cookie `meriter_uzz_session`; path `/trpc/uzz`.
- CookieManager + auth resolve product from header/path.
- Magic link send/redeem accepts `product=uzz` + redirect to `UZZ_WEB_BASE_URL`.
- Mount empty `uzzAppRouter` with `auth.sendEmailLink`, `auth.redeem` (or REST with product), `auth.logout`, `auth.me`.

### Task 2: UZZ schemas + settings

- Models + ports/adapters for settings/bank/lot/deal/ledger/identity-link.
- Defaults from product TZ.
- Register in domain/persistence modules.

### Task 3: Identity linking

- Site: startTelegramLink → code + bot deep link; bot confirms → link.
- Bot: startEmailLink → OTP email → confirm → link.
- `users.getLinkStatus` on uzz router.

### Task 4: Bank emission + admin nominal

- On publication score crossing threshold (community-scoped setting): create bank.
- Holding if no identity link.
- Admin: list awaiting_nominal, setNominal.

### Task 5: Lots + purchase gate

- CRUD lots; list catalog; enforce nudge/require_min_lots.

### Task 6: Deals state machine

- request → accept/reject → complete → close.
- escrow default; fee −1 wallet; hop −1; dealAmountRub = nominal at close.
- Admin cancel/return bank.

### Task 7: Demurrage cron

- Daily −demurrageRubPerDay on active/in_deal; floor; ledger entries.

### Task 8: uzz-web UI

- Scaffold package; email login; all participant + admin screens; TG link UX.

### Task 9: Bot notifications + email link command

- Configurable TG DM; `/email` or button flow.

### Task 10: Dev wiring + deploy docs for cw.ru

- Workspace, scripts, Dockerfile, Caddy snippet, env examples, runbook `17-uzz-*.md`.
- Smoke: lint/build; document cw.ru cutover checklist.

### Task 11: Tests

- Unit/integration for emit, deal close, demurrage, identity link (memory mongo).
