# Сессия 04 — Публикации: создание, черновики, правка, закрытие

**Сайт:** https://dev.meriter.pro  

## Предусловия

- Вход под superadmin.
- Известен ID сообщества **Биржа (МД)**.

---

## 1. Создание поста в Бирже

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 4.1 | Биржа → Создать → Создать пост | Форма с заголовком и текстом | | |
| 4.2 | Заполнить заголовок и описание → опубликовать | Успех; пост в ленте | | |
| 4.3 | Баланс заслуг | Уменьшился на стоимость поста (обычно 1) | | |
| 4.4 | Прикрепить **изображение** в редакторе | Картинка видна в посте | | |
| 4.5 | Отправить пустой заголовок | Ошибка валидации, пост не создаётся | | |

## 2. Черновики

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 4.6 | Открыть `/create` **без** текста | **Нет** баннера «Черновик восстановлен»; счётчик **0/5000** | | |
| 4.7 | Набрать текст → обновить страницу | Черновик восстанавливается (если был реальный текст) | | |
| 4.8 | Опубликовать пост | Черновик очищается | | |

| № | Действие | Ожидаемый результат | Фактически | OK |

## 5. Закрытие, восстановление, удаление

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 4.14 | Закрыть пост (автор или лид — как в UI) | Пост помечен закрытым / уходит из активной ленты | | |
| 4.15 | Восстановить закрытый (если доступно лиду) | Пост снова активен | | |
| 4.16 | Безвозвратное удаление (если есть) | Пост недоступен | | |
