# Сессия 03 — Сообщества, участники, приглашения

**Сайт:** https://dev.meriter.pro  
**Роли:** ваш аккаунт (superadmin, лид) + **второй аккаунт** (инкогнито / отдельный login от команды)

## Предусловия

- Два способа войти под разными пользователями (основное окно + инкогнито).

---

## 1. Список и создание

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 3.1 | `/meriter/communities` | Список сообществ или понятное пустое состояние | | |
| 3.2 | Создать сообщество (кнопка «Создать» / `/meriter/communities/create`) | Форма: название, описание; после сохранения — лента | | |
| 3.3 | Новое сообщество в сайдбаре | В блоке «Администрируемые» | | |
| 3.4 | Записать ID нового сообщества | | | |

## 2. Настройки сообщества (вы — лид)

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 3.5 | `…/settings` — основное | Изменить название → сохранить → отображается в UI | | |
| 3.6 | Вкладка **Права / permissions** | Настройки открываются и сохраняются | | |
| 3.7 | Вкладка **Заслуги / quota** | Без ошибки при сохранении | | |
| 3.8 | Вкладка **Тапалка** (если есть) | Переключатели работают | | |
| 3.9 | Вкладка **Инвестиции** (если есть) | Сохранение без ошибки | | |
| 3.10 | `…/rules` — правила | Текст читаем, страница не падает | | |

## 3. Участники и приглашения

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 3.11 | `…/members` | Вы в списке как лид | | |
| 3.12 | Создать ссылку-приглашение | Ссылка вида `/meriter/join/…` или с токеном | | |
| 3.13 | **Инкогнито:** открыть invite → войти **вторым аккаунтом** | Вступление или заявка | | |
| 3.14 | В members второй пользователь появился | | | |
| 3.15 | Удалить участника / сменить роль (если есть в UI) | Действие только у лида; у участника — запрет | | |
