# Сессия 00 — Подготовка и окружение

**Сайт:** https://dev.meriter.pro

## Что понадобится

- Браузер Chrome или Firefox (актуальная версия).
- **Аккаунт на dev** с ролью **superadmin** (выдаёт команда на ваш основной email).
- Доступ к **почте** для magic link (тот же ящик, что для входа).
- Второе окно **инкогнито** — для второго пользователя или invite-ссылок.
- Блокнот для URL и ID сообществ/проектов.
- Ширина окна: **1280 px** (десктоп) и **390 px** (телефон, DevTools → responsive).
