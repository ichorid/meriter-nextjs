# Сессия 10 — Инвестиции и пересылка постов

**Сайт:** https://dev.meriter.pro  

## Предусловия

- **Биржа (МД)** с включёнными инвестициями (на dev обычно да).
- **Команда** (`typeTag=team`) для пересылки.
- Два пользователя.
