# Сессия 09 — События и переводы заслуг (P2P)

**Сайт:** https://dev.meriter.pro  

## Предусловия

- На dev есть события **или** сообщество/проект с правом создавать события (создайте через UI при необходимости).
- Два аккаунта в одном контексте.

---

## Часть A — События

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 9.1 | `…/communities/{id}/events` | Список событий | | |
| 9.2 | `…/projects/{id}/events` | То же для проекта | | |
| 9.3 | Создать событие | Форма: дата, название, RSVP | | |
| 9.4 | Страница события `/meriter/event/{communityId}/{id}` | **Нет** голосования, пересылки, публикации на Биржу | | |
| 9.5 | RSVP «Пойду» / «Не пойду» | Сохраняется после F5 | | |
| 9.6 | Приглашение по ссылке `/meriter/event/invite/{token}` | В инкогнито: вход → принятие приглашения | | |

## Часть B — Переводы заслуг участникам

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 9.7 | `…/communities/{id}/merit-transfers` | Лента переводов | | |
| 9.8 | Кнопка «Перевести» → выбрать участника → сумма | Диалог с валидацией | | |
| 9.9 | Подтвердить | У отправителя −, у получателя + | | |
| 9.10 | `…/projects/{id}/merit-transfers` | То же в проекте | | |
| 9.11 | `/meriter/profile/merit-transfers` | Входящие и исходящие | | |
| 9.12 | Перевод в контексте **темы события** (если UI есть) | Запись привязана к событию | | |
