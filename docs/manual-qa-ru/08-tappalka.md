# Сессия 08 — Тапалка («Заработать заслуги»)

**Сайт:** https://dev.meriter.pro  

## Предусловия

- Биржа или Проекты с включённой тапалкой.
- В ленте есть **чужие** посты (создайте вторым аккаунтом или используйте существующие).

---

## Шаги

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 8.1 | Лента Биржи: найти «Тапалка» / «Заработать заслуги» | Кнопка/вкладка видна | | |
| 8.2 | Открыть тапалку | Два поста для сравнения | | |
| 8.3 | Первый заход | Короткое обучение (onboarding), можно закрыть | | |
| 8.4 | Выбрать понравившийся пост | Отклик UI, нет ошибки | | |
| 8.5 | Индикатор прогресса | Например «1 из 10» сравнений | | |
| 8.6 | **Свои** посты | **Не показываются** в паре | | |
| 8.7 | Дойти до 10 сравнений (или число из настроек) | +1 заслуга на кошелёк (награда пользователя) | | |
| 8.8 | Победивший пост | Получает заслуги (win reward) | | |
| 8.9 | URL `?tappalka=1` на странице сообщества | Модалка тапалки открывается | | |
| 8.10 | После создания поста — ссылка «заработать» (если есть) | Открывает тапалку | | |
| 8.11 | Недостаточно заслуг для показа | Понятное сообщение, выход без зависания | | |
| 8.12 | **Образы:** тапалки **нет** | Кнопки нет — норма для MVP | | |
