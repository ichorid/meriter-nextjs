# Сессия 07 — Кооперативные проекты, тикеты, Биржа

**Сайт:** https://dev.meriter.pro  

## Предусловия

- Есть команда-сообщество (сессия 03) или на dev уже есть проекты.
- Вход под аккаунтом лида (superadmin).
