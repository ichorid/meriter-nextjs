# Сессия 15 — Проверка фиксов после полного QA

**Сайт:** https://dev.meriter.pro  
**Цель:** убедиться, что баги и UX из твоего полного прогона **исправлены на dev**.  
**Не цель:** полный повтор всех 256 шагов — только пункты ниже.

**Как заполнять:** в колонке **Фактически** коротко что увидел; **OK** = `Да` / `Нет` / `N/A`.  
Если **Нет** — в конце файла заведи дефект (как в README) + скрин/URL.

**Исходные номера** (`Ref`) — шаги из твоего «Чек-лист сессий» / доп.сессии.

---

## Предусловия

- [ ] Залогинен на **dev** (обычный вход, не fake).
- [ ] Есть **второй аккаунт** (инкогнито) для голосов / пересылки / demote.
- [ ] Доступны: хаб **ОБ** (`/meriter/future-visions`), **Биржа (МД)**, хотя бы одна **команда** (`typeTag=team`), один **проект**, сообщество с **документами**.
- [ ] Телефон/узкая ширина (DevTools) для мобильных пунктов.
