# Сессия 06 — Совместные документы

**Сайт:** https://dev.meriter.pro  
**Важно:** недавние исправления UI (рельса предложений, кнопка голоса, доступ админа)

## Предусловия

- Есть сообщество с разделом «Документы» на dev **или** создайте документ через UI.
- Два аккаунта (лид + участник).
