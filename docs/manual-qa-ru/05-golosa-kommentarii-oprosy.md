# Сессия 05 — Голоса, комментарии, опросы, правила MVP-хабов

**Сайт:** https://dev.meriter.pro  
**Нужны два аккаунта:** вы (автор) + второй пользователь (отдельный login или invite)

---

## 1. Голосование за чужой пост (Биржа)

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 5.1 | User B: открыть пост User A → голос **за** с комментарием | Рейтинг +1; комментарий виден | | |
| 5.2 | Текст в popup про квоту и кошелёк | Понятное объяснение на русском | | |
| 5.3 | User B: голос **против** | Списываются только заслуги **кошелька** | | |

## 2. Голос за свой пост

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 5.4 | User A: голос за **свой** пост в Бирже | Только кошелёк; текст: «Вы голосуете за свой **пост**» (не «проект») | | |
| 5.5 | Нулевой баланс кошелька | Понятная ошибка, голос не проходит | | |

## 3. Комментарии

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 5.6 | Оставить комментарий под постом | Отображается в thread | | |
| 5.7 | Вывод заслуг с комментария (если кнопка есть и allowWithdraw) | Заслуги автору комментария | | |

## 4. Опросы

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 5.8 | Биржа или команда: **Создать опрос** | Опрос в ленте; списание заслуг | | |
| 5.9 | Проголосовать в опросе | Голос учтён, результаты обновились | | |
| 5.10 | Редактировать опрос (автор, в окне редактирования) | Сохранение работает | | |

## 5. Образы будущего (ОБ) — особые правила

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 5.11 | Образы: создать пост/карточку ОБ | Разрешено | | |
| 5.12 | Образы: создать **опрос** | **Запрещено** или кнопки нет | | |
| 5.13 | Голос за **свой** пост в Образах | По правилам сообщества (часто разрешён self-vote) | | |
| 5.14 | Вывод заслуг с поста в Образах | **Недоступен** | | |

## 6. Глобальный хаб «Проекты» (team-projects)

| № | Действие | Ожидаемый результат | Фактически | OK |
|---|----------|---------------------|------------|-----|
| 5.15 | Участник (не лид): создать пост в хабе Проекты | Может быть запрет — должно быть **понятное сообщение**, не тихий fail | | |
